# Ioannis Tampakis: portfolio

Personal site built with Next.js (static export), Tailwind CSS and Framer Motion.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static site in ./out
```

All content lives in `src/data/site.ts`. Pushing to `master` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
